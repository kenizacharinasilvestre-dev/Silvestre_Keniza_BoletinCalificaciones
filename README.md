# Boletín de Calificaciones

**Nombre completo:** Keniza Charina Silvestre Martínez  
**Matrícula:** 2026-0044

## Descripción del programa

Este programa permite registrar las calificaciones de un estudiante y conocer el resultado de cada asignatura. También calcula el promedio general y muestra la cantidad de asignaturas aprobadas, en recuperación y reprobadas.

## Datos del programa

**Datos de entrada:**
- Nombre del estudiante.
- Tanda.
- Asignatura.
- Calificaciones de los cuatro períodos.
- Asistencia mínima.

**Datos de salida:**
- Promedio de cada asignatura.
- Situación de cada asignatura.
- Promedio general.
- Cantidad de asignaturas aprobadas.
- Cantidad de asignaturas en recuperación.
- Cantidad de asignaturas reprobadas.
- Situación general del estudiante.

## Tecnología utilizada

- Lenguaje de programación: C#.
- Tipo de aplicación: Windows Forms.
